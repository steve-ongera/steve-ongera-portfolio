# Steve Ongera — Portfolio / Resume Site

Full-stack personal portfolio & resume site.

- **Backend:** Django + Django REST Framework (`/backend`)
- **Frontend:** React + Vite (`/frontend`)
- **Theme:** Matches the supplied reference design — Poppins font, emerald-green
  accent, pill buttons, card-based layout with a two-column main/sidebar homepage.
- **SEO:** Per-page meta tags & Open Graph via react-helmet-async, JSON-LD structured
  data, `sitemap.xml` generated by Django, `robots.txt`, semantic HTML.
- **Images:** Unsplash placeholder URLs on every model field — swap for real photos
  in the Django admin whenever ready.

## Quick start

```bash
# Backend
cd backend
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py createsuperuser
python manage.py seed_data
python manage.py runserver

# Frontend (new terminal)
cd frontend
npm install
cp .env.example .env
npm run dev
```

Visit **http://localhost:5173**. Django admin at **http://127.0.0.1:8000/admin/**.
